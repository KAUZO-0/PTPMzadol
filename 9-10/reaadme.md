### 1.2. Откорректированные требования (после анализа)

На основе анализа и ответов заказчика требования были улучшены и структурированы. Ниже приведён **фрагмент итоговых требований** для АИС «Обработка заявок».

#### Системные характеристики

- **СХ-1:** Приложение является веб-ориентированным, работает по протоколу HTTP/HTTPS.
- **СХ-2:** Приложение разрабатывается на PHP 8.1+ (причина — наличие компетенций у команды поддержки).
- **СХ-3:** Приложение кроссплатформенно (поддерживаются ОС Linux, Windows Server, macOS при наличии веб-сервера и PHP).

#### Пользовательские требования

- **ПТ-1:** Запуск и остановка приложения.
  - ПТ-1.1: Запуск выполняется через обращение к точке входа `index.php`.
  - ПТ-1.2: Остановка приложения не предусмотрена (остановка — остановка веб-сервера).

- **ПТ-2:** Конфигурирование.
  - ПТ-2.1: Настройка выполняется через файл `.env` (пути, подключение к БД).
  - ПТ-2.2: Все данные хранятся в кодировке UTF8.

- **ПТ-3:** Журналирование.
  - ПТ-3.1: Логи пишутся в файл и в БД (таблица `logs`).
  - ПТ-3.2: Администратор может просматривать логи через интерфейс.

#### Бизнес-правила

- **БП-1:** Клиент может создавать заявки только после авторизации.
- **БП-2:** Оператор может создавать заявку за клиента.
- **БП-3:** Статус заявки изменяется только по схеме:  
  `Новая → В работе → Выполнена` или `Новая → Отклонена`.

#### Атрибуты качества

- **АК-1:** Производительность.
  - АК-1.1: Время отклика API ≤ 500 мс при 100 запросах/сек на эталонном оборудовании (CPU 4 ядра, RAM 8 ГБ, SSD).

- **АК-2:** Устойчивость.
  - АК-2.1: Приложение не должно падать при некорректном вводе.
  - АК-2.2: Файлы > 50 МБ не обрабатываются.

#### Ограничения

- **О-1:** Использование PHP обусловлено возможностью заказчика поддерживать систему.
- **О-2:** Версия PHP — 8.1+, требуется расширение `pdo_mysql`, `json`, `session`.
- **О-3:** Установка и настройка веб-сервера не входят в рамки проекта.

#### Детальные спецификации (фрагмент)

- **ДС-1:** База данных — MySQL 8.0+.
- **ДС-2:** Формат лога: `[YYYY-MM-DD HH:MM:SS] [LEVEL] Сообщение`.
- **ДС-3:** При ошибках параметров выводится сообщение с подсказкой.
- **ДС-4:** Заявка содержит: ID, клиент, тип, описание, адрес, статус, дату создания.
